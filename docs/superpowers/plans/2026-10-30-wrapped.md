# PriceWise Wrapped Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A story-style "Wrapped" page that summarizes a user's savings across all their shopping lists, with a two-line cumulative chart.

**Architecture:** One pure-ish service in `shopping_lists/services.py` computes every number from three queries; a second function turns the per-list totals into SVG geometry. A Django view renders all 8 cards server-side as a stacked page; a small vanilla JS file turns that page into one-card-at-a-time stories.

**Tech Stack:** Django 6.0, templates, vanilla JS, inline SVG. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-30-wrapped-design.md`

## Global Constraints

- Only lists with `owner = request.user`, ordered by `created_at`, then `pk`.
- Per item, with current `Price` rows: with = min price × quantity; without = max price × quantity; saved = without − with. Products with no price add nothing and are counted in `unpriced_items`.
- "Sin PriceWise" = most expensive supermarket (not average).
- Profiles: saved_pct < 5 → "Comprador tranquilo"; 5 ≤ pct ≤ 15 → "Buen ojo"; > 15 → "Cazador de ofertas".
- If total without = 0, saved_pct = 0.
- Query count must not grow with lists or items (target: 3 queries in the service).
- SVG coordinates inside `{% localize off %}`.
- Login required; anonymous users are redirected to login like the other list views.
- Keyboard: arrows and space move, Escape goes to `/?open_lists=true`. `prefers-reduced-motion` disables transitions. Without JS, cards stack vertically.
- No new dependencies; keep the green/black/cream identity.

## Review Focus

- A user with zero lists sees one invitation card, not 8 empty ones (Task 1 test + Task 3 test).
- Lists with no items and items with no price never crash and add $0 (Task 1).
- A product priced in only one supermarket adds to spending but $0 to savings, and does not count for "tu supermercado" (Task 1).
- Another user's lists never leak into the totals (Task 1, Task 3).
- One list: no chart, the "crea otra lista" message instead (Task 2, Task 3).
